# Planning & Tickets

Skills for turning ideas into executable work:

- **`to-spec`** (`.agents/skills/to-spec/SKILL.md`) — synthesise the current conversation into a spec and publish it as a GitHub issue. No interview, just synthesis.
- **`to-tickets`** (`.agents/skills/to-tickets/SKILL.md`) — break a plan or spec into tracer-bullet tickets with blocking-edge declarations, published to GitHub Issues.
- **`wayfinder`** (`.agents/skills/wayfinder/SKILL.md`) — plan a large chunk of work (too big for one agent session) as a shared map of decision tickets; resolve them one at a time until the path is clear.
- **`implement`** (`.agents/skills/implement/SKILL.md`) — implement a piece of work given a spec or a set of tickets. Use after `to-tickets` or `to-spec` to drive execution.
